# Dad Joke Showdown

A program that writes one dad joke of at most 200 characters to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output directory defaults to `/output`. The program creates it when needed. Node 22, standard library only, deterministic — no network, no randomness.

Made for [make.fun](https://make.fun).
